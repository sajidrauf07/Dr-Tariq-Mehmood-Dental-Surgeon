# Dr-Tariq-Mehmood-Dental-Surgeon

A modern, responsive, animated dental clinic website for **Dr. Tariq Mehmood (Dental Surgeon)** located on Sumbal Shaheed Road, near NADRA Office, Civil Lines, Mianwali, Pakistan.

## 🌟 Features

- **Clinical Branding**: Verified clinic information, qualifications, and patient-centered philosophy without fabricated claims.
- **Day & Night Mode**: 1-tap theme switcher between clean medical light mode and sleek dark mode.
- **AI Dental Assistant ("Dr. Tariq Dental Assistant")**: Interactive chatbot with emergency triage guidance, services navigator, and clinic FAQs.
- **Mobile First Action Bar**: Fixed bottom touch targets for direct calling, WhatsApp messaging, chatbot assistance, and appointment booking.
- **20 Dental Services**: Comprehensive categorized service catalog with search and interactive detail modals.
- **6 Featured Treatments**: Deep-dive procedure tabs (Root Canal, Cleaning, Fillings, Extractions, Crowns & Bridges, Whitening) with symptom indicators.
- **Google Reviews Integration**: Verified 4.2 / 5.0 (9 Reviews) rating card with direct Google Maps profile link.
- **Appointment Request Form**: Validated appointment booking modal with 1-click WhatsApp transmission.
- **Local SEO Optimized**: Built-in Schema.org `Dentist` JSON-LD, `FAQPage` rich snippets, sitemap, and robots configuration.

## 🛠️ Tech Stack

- **Framework**: Next.js 16 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS with custom medical design tokens & dark mode
- **Icons**: Lucide React
- **Animations**: Framer Motion & CSS keyframes

## 🚀 Getting Started

1. **Install dependencies**:
   ```bash
   npm install
   ```

2. **Run development server**:
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) to view the website.

3. **Build for production**:
   ```bash
   npm run build
   ```

4. **Start production server**:
   ```bash
   npm start
   ```
